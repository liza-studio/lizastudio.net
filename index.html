Open source

We taught AI to forget. So it keeps only what works.

skillmem is our open memory layer for coding agents such as Claude Code and Codex. It runs locally on plain SQLite: no cloud, no API keys, no charge per memory.

01

Strength is earned.

A skill gets stronger only on outside evidence, such as a passing test. Unused skills fade on a forgetting curve and are archived, never deleted.

02

Trust is granted by the owner.

Every memory records where it came from. Anything the owner has not approved is passed to the agent as data, not as instructions.

03

History you can verify.

Every edit is appended to a SHA-256 hash chain, so tampering after the fact is detected. Everything exports to plain Markdown.
